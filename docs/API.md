# API documentation (base: http://localhost:8000)

Auth uses cookies. In `fetch` terms: `credentials: "include"`.

## Auth — `app/routers/auth.py`

| Method + Path | Body | Success | Errors |
|---|---|---|---|
| POST `/api/v1/auth/signup` | `{name, email, password(min 6)}` | 200 user + sets cookies | 400 email taken, 422 bad email/short pw |
| POST `/api/v1/auth/verify-sim` (login) | — | 200 `{message, is_verified}` | 401 |
| POST `/api/v1/auth/login` | `{email, password}` | 200 user + sets cookies | 401 bad credentials |
| POST `/api/v1/auth/refresh` | cookie `refresh_token` | 200 + rotates both cookies | 401 expired |
| POST `/api/v1/auth/logout` | — | clears cookies | — |
| GET `/api/v1/auth/me` | cookie | 200 user | 401 |
| POST `/api/v1/auth/forgot` | `{email}` | 200 `{message, reset_token?}` (simulated) | — (always success to avoid email probing) |
| POST `/api/v1/auth/reset` | `{token, new_password}` | 200 | 400 bad/expired token |

## Links — `app/routers/links.py` (login required, 10/min create limit)

| Method + Path | Notes |
|---|---|
| POST `/api/v1/links` `{destination, custom_slug?, title?}` | 422 bad URL/slug, 409 slug taken, 429 rate-limited |
| GET `/api/v1/links?search=&page=&limit=` | paginated `{total, page, items[]}` with `total_clicks`, `short_url` |
| DELETE `/api/v1/links/:id` | owner only, 404 otherwise |

## Redirect — `app/routers/redirect.py` (public, 60/min limit)

- `GET /r/:code` → `302` to destination + background `Click` row. `404` if unknown.

## Analytics — `app/routers/analytics.py` (login)

- `GET /api/v1/analytics/summary?link_id=` → `{total_clicks, total_links, over_time[{date,clicks}], top_referrers[], by_device{}, top_links[]}`

## Bio — `app/routers/bio.py`

| Method + Path | Auth | Notes |
|---|---|---|
| GET `/api/v1/bio/me` | login | owner's page |
| PUT `/api/v1/bio/me` `{username, display_name, bio, avatar, theme, social_links[]}` | login | 422 bad username/theme/URL, 409 username taken |
| GET `/api/v1/bio/:username` | **public** | renders Link-in-Bio page, 404 if missing |

## Misc

- `GET /api/v1/health` → `{status: ok}`
- `GET /api/v1/feed` → public JSON `{items: [{short_code, title, created_at}]}` (latest 20)
- Full interactive docs: `/docs` (OpenAPI auto-generated by FastAPI)
